# Privacy Policy - GK Snippets

GK Snippets is a personal, non-commercial project that publishes daily general-knowledge quiz videos to its own YouTube channels via the YouTube Data API.

- The app accesses only the YouTube channels owned by the project owner, solely to upload videos the owner created.
- No user data is collected, stored, shared, or sold. No analytics on viewers, no tracking, no cookies.
- No third parties receive any data.
- OAuth tokens are stored as encrypted GitHub repository secrets and are used only by the project's own automation.
